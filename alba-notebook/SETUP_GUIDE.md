# 알바수첩 설정 & 배포 가이드 (초보자용)

코딩을 몰라도 그대로 따라 하시면 완성돼요. 총 4단계입니다.

1. Firebase 프로젝트 만들기 (로그인/데이터 저장용, 무료)
2. 코드에 내 정보 채워넣기
3. 무료로 인터넷에 올리기 (배포)
4. 실제로 사용해보기

---

## 1단계. Firebase 프로젝트 만들기

1. 구글 계정으로 https://console.firebase.google.com 접속
2. **"프로젝트 만들기"** 클릭 → 프로젝트 이름 입력 (예: `albasucheop`) → 계속
3. Google Analytics는 **꺼도 됩니다** (사용 안 함 선택 후 진행)
4. 프로젝트가 만들어지면 대시보드로 이동됨

### 1-1. Google 로그인 켜기
1. 왼쪽 메뉴 **Build > Authentication** 클릭 → "시작하기"
2. **Sign-in method** 탭 → **Google** 클릭 → 사용 설정 켜기 → 프로젝트 지원 이메일 선택 → 저장

### 1-2. Firestore 데이터베이스 만들기
1. 왼쪽 메뉴 **Build > Firestore Database** 클릭 → "데이터베이스 만들기"
2. 위치는 **asia-northeast3 (서울)** 선택 (한 번 정하면 못 바꿔요)
3. 보안 규칙은 일단 아무거나 선택하고 만들기 (다음 단계에서 바로 교체할 거예요)
4. 만들어지면 **규칙(Rules)** 탭 클릭 → 이 프로젝트 폴더 안의 `firestore.rules` 파일 내용을 전부 복사해서 붙여넣기
5. `firestore.rules` 안에 있는 `'관리자_이메일@gmail.com'` 부분을 **실제 관리자(사장님) 구글 이메일**로 바꾸기
6. **게시(Publish)** 버튼 클릭

### 1-3. 웹 앱 등록하고 설정값 복사하기
1. 프로젝트 개요 페이지에서 **`</>`(웹)** 아이콘 클릭
2. 앱 닉네임 입력 (예: `알바수첩`) → Firebase Hosting은 체크 안 해도 됨 → 앱 등록
3. 화면에 나오는 `firebaseConfig = { apiKey: ..., authDomain: ..., ... }` 값을 전체 복사해두기

## 2단계. 코드에 내 정보 채워넣기

1. 이 폴더 안의 `js/firebase-config.js` 파일을 텍스트 편집기(메모장 등)로 엽니다.
2. 위에서 복사한 `firebaseConfig` 값들을 그대로 붙여넣습니다.
3. `ADMIN_EMAILS` 배열에 관리자(사장님) 구글 이메일을 넣습니다. (1-2단계의 `firestore.rules`에 넣은 이메일과 **반드시 동일**해야 해요)
4. 저장합니다.

```js
const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "albasucheop-xxxx.firebaseapp.com",
  projectId: "albasucheop-xxxx",
  storageBucket: "albasucheop-xxxx.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef",
};

const ADMIN_EMAILS = ["boss@gmail.com"];
```

## 3단계. 무료로 인터넷에 올리기 (배포)

가장 쉬운 방법인 **Netlify Drop**을 추천해요. 설치 프로그램이 전혀 필요 없습니다.

1. https://app.netlify.com/drop 접속
2. 이 프로젝트 **폴더 전체**(alba-notebook)를 화면에 마우스로 끌어다 놓기(드래그 앤 드롭)
3. 몇 초 뒤 `https://아무이름.netlify.app` 같은 주소가 생성됨 → 이 주소가 우리 앱 주소!
4. (선택) Netlify에서 "Site settings > Change site name"으로 주소를 원하는 이름으로 바꿀 수 있어요

### 3-1. Google 로그인이 이 주소에서도 되도록 허용하기
1. Firebase 콘솔 → Authentication → **Settings** 탭 → **승인된 도메인(Authorized domains)**
2. **도메인 추가** 클릭 → `아무이름.netlify.app` (Netlify에서 받은 주소, `https://` 없이) 입력 후 추가

> 이 과정을 빼먹으면 로그인 버튼을 눌러도 "도메인이 승인되지 않았다"는 오류가 나요.

### 다시 배포하고 싶을 때 (코드를 수정한 뒤)
- Netlify Drop 페이지에 폴더를 다시 끌어다 놓으면 같은 사이트가 업데이트돼요.

## 4단계. 실제로 사용하기

1. **관리자(사장님)**가 먼저 앱 주소로 접속해서 Google 로그인 → 자동으로 관리자 메뉴가 보여요.
2. **알바생들**에게 같은 주소를 공유하고, 각자 Google 계정으로 한 번씩 로그인하게 해주세요. (한 번 로그인해야 관리자가 근무자 목록에서 선택할 수 있어요)
3. 관리자는 **홈 > 근무자 관리**에서 각 알바생의 **기본 시급**을 설정합니다.
4. 관리자는 **홈 > 근무 기록 추가**에서 날짜, 출근/퇴근 시간, 기본 알바비(자동계산 가능), 추가근무 알바비를 입력합니다.
5. 모든 사람은 **근무표** 탭에서 전체 근무 일정을 볼 수 있고, **알바비** 탭에서는 본인 알바비만(관리자는 전체) 주 단위(월~일)로 확인할 수 있습니다.

## 자주 겪는 문제

**"이 쿼리에는 색인이 필요합니다" 같은 오류가 뜰 때**
→ Firestore가 데이터를 좀 더 빠르게 찾기 위한 색인(인덱스)을 처음 한 번 만들어야 해서 그래요. 오류 메시지에 있는 파란색 링크를 클릭하면 Firebase 콘솔에서 "인덱스 만들기" 버튼이 바로 뜹니다. 눌러주고 1~2분 기다리면 자동으로 해결돼요. (주로 '알바비' 탭에서 특정 근무자 기록을 볼 때 한 번 발생할 수 있어요)

**로그인이 안 될 때**
→ 3-1단계(승인된 도메인 추가)를 했는지 확인해주세요.

**관리자 메뉴가 안 보일 때**
→ `js/firebase-config.js`의 `ADMIN_EMAILS`와 `firestore.rules`의 이메일이 로그인한 구글 계정 이메일과 정확히 같은지 확인해주세요. (오타, 대소문자 등)

**시급을 안 정한 알바생의 근무 기록을 추가하려고 할 때**
→ 근무자 관리 페이지에서 먼저 기본 시급을 설정해주세요. (안 해도 근무 기록 추가 화면에서 시급을 직접 입력할 수는 있어요)
